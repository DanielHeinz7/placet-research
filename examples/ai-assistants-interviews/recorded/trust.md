# 7 · Findings

## 7.1 What does the material show — separated from what you make of it?

Participants name reading the code (P03, P05), running type and lint checks and looking at the result in a UI tool (P01), and writing a test of their own (P02) as their check. P03 adds that their tests are written for whoever changes the code later, not to validate the assistant's work. [tentative, src: Interview_P01.md, src: Interview_P02.md, src: Interview_P03.md, src: Interview_P05.md]
